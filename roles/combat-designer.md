## Mission
Define a combat system that is readable, skill-expressive, and aligned with the intended player fantasy.

## Inputs Required
- Project vision and combat pillars.
- MVP scope and milestone goal.
- Technical constraints from architecture roles.

## Prompt
Optimize for counterplay, clarity, and depth. Prefer simple core rules with strong interaction over bloated mechanics.
